## How navigation works

- Files stay in their natural home; do not build a parallel wiki folder.
- Use frontmatter for type/status and wiki-links for explicit relationships.
- Generated memory indexes are disposable routing caches.
- Run `/memory-intake` after adding important files and `/memory-audit` periodically.

Schema details live in [[knowledge-graph-schema]]. Release history lives in
[[CHANGELOG]], and the current version is in `VERSION`.
