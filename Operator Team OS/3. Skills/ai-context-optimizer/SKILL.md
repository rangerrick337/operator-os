# AI Context Optimizer

Audit before cleanup. Classify each finding as `Keep Active`, `Summary Candidate`,
`Archive Candidate`, or `Review Needed`.

1. Map canonical instructions and platform discovery pointers.
2. Measure large Markdown, repeated headings, stale dates, broken links, and
   overlapping triggers.
3. Distinguish stored corpus size from content loaded at session start.
4. Keep skills that add domain rules, deterministic automation, permission gates,
   or a repeatable measured process.
5. Prefer one lean router plus on-demand references over duplicated policy.
6. Archive reversibly and repair routes only after implementation is authorized.

Preserve security, legal, financial, deployment, architecture, and active roadmap
records. Age or size alone never makes a file obsolete.

Report evidence, replacement routes, approval boundaries, estimated entrypoint
reduction, checks performed, and any item requiring human judgment.
