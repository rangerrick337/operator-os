# Operator OS 2.0 Refresh

## Outcome

Port the most reusable operating-system design lessons into the public template
without including company data, identities, credentials, or vendor-specific jobs.

## Included

- Canonical policy plus portable discovery pointers
- Knowledge-graph schema and WIKI
- Query-first memory retrieval and atomic session logs
- Human-gated Long-Term memory proposals
- Memory, start, audit, intake, and wrap-up routing
- Context audit and workspace health checks
- Release metadata, setup guidance, and repository hygiene

## Excluded

- Private knowledge and memory
- Organization-specific taxonomies, brands, users, automations, and integrations
- Automatic deployment, sending, spending, or recurring background jobs

## Verification

- Python unit and smoke tests
- Workspace doctor
- Link/path/privacy scan
- Manifest generation and Git diff review
