# Memory Intake

Bring a file or folder into the knowledge graph without duplicating its content.

1. Confirm the library and its permission boundary.
2. Skip dependencies, caches, generated output, temp, and archives.
3. For Markdown, merge the frontmatter required by [[knowledge-graph-schema]],
   apply approved tags, and add only useful, explicit wiki-links.
4. For PDFs, documents, sheets, and media, create a Markdown companion only when
   there are findings, obligations, or decisions worth capturing. A filename and
   folder are usually enough.
5. Never modify a source artifact merely to index it.
6. Record a concise session handoff and rebuild the retrieval index.

Do not invent facts, create a summary for every asset, or build a parallel wiki.
